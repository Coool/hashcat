## *hashcat* ##

**hashcat** ir pasaules ātrākais un vismodernākais paroles atgūšanas rīks, kas atbalsta piecus unikālus laušanas veidus vairāk nekā 300 ļoti optimizētiem jaukšanas algoritmiem. hashcat pašlaik atbalsta centrālos procesorus, videokartes un citus aparatūras paātrinātājus laušanas ātruma palielināšanai Linux, Windows un macOS operētājsistēmās, un palīdz īstenot izplatītu paroļu uzlaušanu.
